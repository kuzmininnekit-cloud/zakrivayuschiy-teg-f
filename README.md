# Проект 4 спринта (Закрывающий тег)

## Описание

В этой проектной работе нужно было сверстать сайт для мобильной версии и для десктопа.

Используя svg-изображения, работу с анимацией, эффекты для кнопок и всплывающее окно получилось сделать сайт с контентом, состоящим из карточек с описанием прошедших спринтов и ощущениями после них.
